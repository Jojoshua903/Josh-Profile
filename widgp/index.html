How to play

  1. Set up your group once. Start a sketchbook, add your friends' names in turn order and write a prompt.
  2. Send it to the next person. WidGP tells you whose turn it is and copies a message with the link. Send it to them privately, so nobody else peeks.
  3. Turns alternate. Got words? Draw them. Got a drawing? Describe it in words. You only ever see the page right before yours.
  4. Keep it moving. The link holds the whole sketchbook, so after your turn you send your own new link to the next person.
  5. When the last page is filled, the reveal unlocks. Post the reveal link in your group chat and flip through it together, with every drawing replaying stroke by stroke.

Play it like Gartic Phone: everyone in the group starts their own sketchbook at the same time. They all go round in different orders, so you end up with one reveal per person. When a sketchbook reaches you, there's a button to start your own with the same group.

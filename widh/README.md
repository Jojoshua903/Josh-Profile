# WidH · Wat in de Hunt

A Duck Hunt style shooter starring the WidR 64 crew from [joshibrahim.nl](https://joshibrahim.nl): Ratjetoe, Dih, Thomas, Milo, Josh and the dreaded Meta AI, with Guiseppe the apple as the hunting dog.

## Play

Open `index.html` in a browser. No build step, no dependencies.

- Click to shoot, 3 shells per pair of targets
- Hit enough of the 10 targets per round to advance
- Let Meta AI escape and your crosshair gets scrambled

## Host on GitHub Pages

1. Push `index.html` to a repo
2. Settings → Pages → Deploy from branch → `main` / root
3. Visit `https://<your-username>.github.io/<repo-name>/`

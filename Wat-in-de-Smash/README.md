# Wat In De Fighters - Super Smash Bros Style Platform Fighter

A complete, self-contained browser platform fighter inspired by **Super Smash Bros**, featuring all characters and lore from [joshibrahim.nl/wat-in-de-fighters.html](https://joshibrahim.nl/wat-in-de-fighters.html).

---

## 🎮 How to Play

Open [index.html](file:///Users/jrcompany903/.gemini/antigravity/scratch/wat-in-de-fighters/index.html) in your browser:

```bash
# On macOS:
open /Users/jrcompany903/.gemini/antigravity/scratch/wat-in-de-fighters/index.html
```

Or serve with any static server:
```bash
npx serve /Users/jrcompany903/.gemini/antigravity/scratch/wat-in-de-fighters
# or
python3 -m http.server 8080 --directory /Users/jrcompany903/.gemini/antigravity/scratch/wat-in-de-fighters
```

## 🕹️ Controls

### Player 1 (Keyboard)
| Action | Key |
|---|---|
| **Move Left / Right** | `A` / `D` |
| **Crouch / Drop Down Platform** | `S` |
| **Jump / Double Jump** | `W` (or `Space`) |
| **Attack (Jab / Tilts / Smashes)** | `J` (or `F`) |
| **Special Attack** | `K` (or `G`) |
| **Super / Final Smash (when gauge full)** | `L` (or `H`) |
| **Shield / Dodge Roll** | `Shift` / `E` |
| **Taunt** | `T` |

### Player 2 (Local Versus)
| Action | Key |
|---|---|
| **Move Left / Right** | `Arrow Left` / `Arrow Right` |
| **Crouch** | `Arrow Down` |
| **Jump** | `Arrow Up` |
| **Attack** | `NumPad 1` (or `P`) |
| **Special** | `NumPad 2` (or `[` / `O`) |
| **Super** | `NumPad 3` (or `]`) |
| **Shield** | `NumPad 0` (or `RShift`) |

*Gamepads & mobile touch controls are also natively supported!*

## 🏟️ Stages & Modes

- **Stages**: Nederland, Zoetermeer, Japan, USA, Russia, Turkey, Italy, Ireland, Spain, Australia, etc.
- **Game Modes**:
  - **Standard Stock / Time Match**: Classic Smash rules with knockback percentages, blast zones, and ledge recoveries.
  - **Campaign Mode & Classic Mode**: Single-player ladder with bonus stages, mini-bosses, and giant boss battles.
  - **Soccer Mode**: Knock the ball into the opponent's goal.
  - **Sudden Death / Low Gravity / Fast / One-HP**: High-stakes modifier rules.
  - **Skin & Accessory Customizer**: Customize character palettes, hats, and skins.
  - **Lore Journal & Skill Tree**: Unlock facts, stats, and power-up perks as you play.

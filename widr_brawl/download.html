WAT IN DE BRAWL

1 · Download the game

One ZIP with everything the repo needs: index.html, data.js, engine.js, render.js and README.md.

Or grab the files one by one:

2 · Put it on GitHub

  1. Unzip the download.
  2. On github.com click + → New repository, name it (e.g. widbs), make it Public, create it.
  3. Click uploading an existing file, drag all 5 files in (not the folder), then Commit changes.

3 · Make it playable online

  1. In the repo open Settings → Pages.
  2. Source: Deploy from a branch, branch main, folder / (root), Save.
  3. After a minute it's live at https://your-username.github.io/widbs/.
